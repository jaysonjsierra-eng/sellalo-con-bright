# Avisos de terceros

Este proyecto distribuye recursos de las siguientes dependencias:

- Archivo Black, mediante `@fontsource/archivo-black` 5.3.0. Fuente bajo SIL Open Font License 1.1.
- DM Sans, mediante `@fontsource/dm-sans` 5.3.0. Fuente bajo SIL Open Font License 1.1.
- Solar Icons, mediante `@solar-icons/static` 2.1.0. Paquete bajo licencia MIT; iconos de 480 Design bajo CC BY 4.0.

Los archivos de licencia completos de cada dependencia quedan disponibles después de ejecutar `npm install` dentro de sus carpetas correspondientes en `node_modules`.
